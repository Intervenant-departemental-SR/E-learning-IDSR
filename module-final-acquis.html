Module final · Formation initiale IDSR

Questionnaire des acquis et attestation de suivi

Dernière étape du parcours de préparation : quatorze questions, deux par module, puis la génération de l'attestation déclarative de suivi des sept modules.

Accès au module final

Le module final s'ouvre lorsque les sept modules de préparation sont validés.

    La progression est enregistrée dans ce navigateur : les modules doivent être suivis sur le même appareil et avec le même navigateur que le module final.

    Questionnaire des acquis

    Deux questions par module, sur les notions essentielles de la préparation.

    Chaque question est validée par la bonne réponse. Une réponse erronée peut être corrigée autant de fois que nécessaire : un lien permet de revoir le module concerné.

    L'attestation se génère une fois les quatorze questions réussies. Les réponses sont conservées dans ce navigateur.
